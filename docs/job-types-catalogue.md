# Job Grid starter job-type catalogue

## What is published on the website

The public directory contains 496 distinct base role titles grouped into 25 categories, derived from the uploaded job-title workbook. Repeated base occupation titles and automatically generated specialization/setting variants were not promoted as separate role types in the public catalogue.

## Important boundary

These entries are **job types, not job advertisements**. The workbook did not provide official occupational codes, verified source evidence, named real employers, verified work locations, pay details, application destinations, or confirmation that a vacancy is open. The website must not display those fields as if they were known.

The directory is a useful starter experience while the marketplace is new. Every role type remains subject to review against appropriate occupational references and local usage. Do not mark a role as officially classified or verified without evidence.

## Real vacancies

Real employer vacancies belong in the public.jobs table. They should only be published when an administrator has reviewed the employer-supplied title, employer, job description, work location, category, skill level, application route, and publication/expiry dates. The existing database policy exposes only rows with status = 'published' that are within their publication window.

When employers begin adding vacancies, those vacancy cards should be shown separately from the role-type directory. If a role type is later found to be misleading or invalid, remove it from the public catalogue or mark it inactive through a reviewed catalogue update; do not silently turn catalogue entries into purported vacancies.
